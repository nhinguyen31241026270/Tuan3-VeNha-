Heroes of JavaScript and HTML
Heroes of JavaScript and HTML is a "Heroes of Might and Magic"-like game, but for code nerds. Each hero has its unique coding abilities and can develop software applications.

Currently the game has only four hero types:

Front-end Developer

👨‍💻
Being the ultimate masters of JavaScript, the order of the Front-enders is known to create user interfaces that fill users with absolute pleasure.

Mobile Developer

📱
The movement of the Mobile developers is brand new, yet in their short time they already manage to amaze people with their applications.

Web Developer

🌐
The secret of the Web developers is the oldest there is. They prefer the old ways and rarely move to modern solutions.

QA Engineer

🔍
The QAs are the designers of fates! They always have the final word, and all gods and mortals are bound to obey them.
